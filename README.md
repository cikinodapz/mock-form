# ✦ Gemini AutoFill — Ekstensi Chrome

Ekstensi Chrome untuk mengisi form otomatis menggunakan **Google Gemini Flash 2.5 Lite** (GRATIS).

---

## 🚀 Cara Install

### 1. Persiapan File
Ekstrak folder `gemini-autofill` ke lokasi yang mudah diakses (misal: Desktop).

### 2. Buka Chrome Extensions
- Buka Chrome → ketik di address bar: `chrome://extensions/`
- Aktifkan **Developer Mode** (pojok kanan atas)

### 3. Load Ekstensi
- Klik tombol **"Load unpacked"**
- Pilih folder `gemini-autofill`
- Ekstensi siap digunakan! ✓

---

## 🔑 Dapatkan API Key GRATIS

1. Buka: https://aistudio.google.com/app/apikey
2. Login dengan akun Google
3. Klik **"Create API Key"**
4. Copy API Key
5. Buka popup ekstensi → tab **Setelan** → paste API Key → Simpan

---

## 📖 Cara Penggunaan

### Isi Form Otomatis
1. Buka halaman web yang memiliki form
2. Klik ikon ekstensi di toolbar
3. Tab **"Isi Form"** → tulis instruksi
4. Contoh instruksi:
   - *"Isi dengan nama saya John Doe, email john@email.com, telepon 08123456789"*
   - *"Isi form registrasi untuk perusahaan Acme Corp, posisi Software Engineer"*
   - *"Isi dengan data fiktif yang masuk akal untuk testing"*
5. Klik **"✦ Isi Otomatis"**

### Scan Dulu (Opsional)
- Klik **"🔍 Scan"** untuk melihat field yang terdeteksi sebelum mengisi

### Profil Tersimpan
- Simpan data yang sering dipakai di tab **"Profil"**
- Klik tombol ▶ untuk memuat profil ke instruksi

- ✅ Deteksi form otomatis (input, textarea, select, checkbox, radio)
- ✅ AI mengisi nilai yang sesuai konteks
- ✅ Support form React/Vue (trigger event native)
- ✅ Highlight field yang terisi
- ✅ Profil data tersimpan
- ✅ Bersihkan form dengan satu klik
- ✅ Gratis (menggunakan Gemini Flash Lite)

---

## ⚠ Catatan

- API Key disimpan lokal di browser, tidak dikirim ke server lain
- Ekstensi hanya mengakses halaman yang sedang aktif
- Tidak berfungsi di halaman chrome:// atau halaman yang diproteksi
