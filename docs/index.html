Quick Setup

Install in Under 2 Minutes

mock-form is 100% open source under the MIT License. Install unpacked in Chrome with zero build steps required.

01

Clone or Download

Clone the GitHub repository to your local computer, or download the latest ZIP release archive.

git clone https://github.com/cikinodapz/mock-form.git
02

Load Unpacked in Chrome

Open Chrome, navigate to chrome://extensions, toggle Developer mode (top right), and click Load unpacked to select the folder.

chrome://extensions
03

Add Free Gemini API Key

Generate a free API key from Google AI Studio, paste it into the extension Settings tab, and start autofilling immediately.
